6. Get Single AI Call Log Detail
Purpose: Fetches the complete, detailed record of a specific AI transaction, including full prompt payloads, raw engine outputs, and sanitized error messages if an error occurred.
Method: GET
URL: http://localhost:8080/admin/logs/{logId}
Path Parameter:
logId: UUID string obtained from the GET /admin/logs response.
Headers:
Authorization: Bearer <accessToken>
